# Aplicacion web VidaFit

Esta es una aplicacion web que intenta solucionar el problema planteado por VidaFit Gym,
lamentablemente no tuve el tiempo para añadirle las funcionalidades necesarias para la base de datos.

## Funcionalidades Principales

* Se crea alerta al presionar reservar.

## Funcionalidades que se deben implementar para los usuarios

* Registrarse e iniciar sesión.
* Ver las clases disponibles por día y hora
* Reservar su cupo en una clase.
* Cancelar o modificar su reserva.
* Consultar su historial de reservas.
* Recibir notificaciones o recordatorios.


## Funcionalidades que se deben implementar para el administrador

* Crear y modificar horarios de clases.
* Ver reportes básicos de asistencia.
* Bloquear temporalmente clases si es necesario.


## Tecnologías Utilizadas

* HTML
* CSS
* JavaScript
